Автопортретная фотостудия — автоматическая система съёмки

Этот проект создавался для автопортретной фотостудии, которую открыла моя жена. Основная проблема: фотоаппарат физически невозможно подключить одновременно к ноутбуку (для передачи снимков) и к пульту дистанционного управления. Решение пришло через использование беспроводного пульта, который при подключении к ноутбуку изменяет громкость системы. Именно это изменение стало триггером для автоматической съёмки.

Как это работает:

    Программа отслеживает уровень громкости в системе. Как только громкость меняется (пульт нажат) — отправляется горячая клавиша Ctrl+Alt+Space в приложение digiCamControl, которое делает снимок.

    Фотография автоматически копируется в папку резервного хранения на рабочем столе.

    При необходимости снимок конвертируется в чёрно‑белый вариант и сохраняется рядом.

    Если включена интеграция с Яндекс.Диском, фото загружаются в облако, а папка с сессией становится публичной. Для быстрого доступа генерируется QR‑код.

    На втором мониторе (например, для клиента) отображается последний сделанный кадр, повёрнутый в портретную ориентацию.

Ключевые возможности:

    🎛️ Триггер съёмки по изменению громкости (работает с любым пультом, управляющим громкостью ПК)

    📸 Автоматическое сохранение всех фото в структурированные папки по дате и времени

    🖼️ Конвертация в ч/б на лету

    ☁️ Загрузка на Яндекс.Диск + генерация QR‑кода для мгновенного доступа к снимкам

    🖥️ Вывод фото на второй монитор для демонстрации

    🛠️ Проверка окружения при запуске: наличие digiCamControl, папок сессии и резерва

Проект написан на Python с использованием tkinter/customtkinter для графического интерфейса и полностью автономен. Он создавался для упрощения работы в студии и теперь успешно используется в повседневной съёмке.
